# 素材仕様

## 方針

怪しげな現代風の古い事務所ビルを、新規素材で表現します。灰色とくすんだ緑の壁、磨耗したタイル、古い吸音天井板、錆びた設備を使います。人物・血痕・怪物・物語上の手掛かりは素材に加えていません。

## 壁・床・天井

`assets/textures/building-atlas.png` は画像生成スキルの標準画像生成で作成した新規アトラスです。生成した画像を加工せず、そのまま収録しています。四等分した左上が壁、右上が床、左下が天井、右下が塗装鋼板です。

切り出しは描画時の正規化矩形で行います。壁は `(0,0,0.5,0.5)`、床は `(0.5,0,0.5,0.5)`、天井は `(0,0.5,0.5,0.5)` です。右下の鋼板は現版では素材予備です。AI画像のため、繰り返し境界を数学的に完全なシームレスとは保証しません。実画面での見た目を優先して確認します。

英語の制作プロンプトと日本語指定は [制作プロンプト](../assets/source/material-prompt.md) に保存しています。再生成すると画素は変わるため、固定したPNGが正本です。

## 設備

`assets/fixtures/` の設備は今回作成したSVGです。`tools/create-fixtures.mjs` に編集可能な元コードを収録しています。

`power-panel.svg` と `power-panel-on.svg` は配電盤の消灯・点灯状態です。`intercom.svg` は古いインターホン、`notice-board.svg` は掲示板、`steel-door.svg` は鉄扉、`window.svg` は曇りガラス、`vent.svg` は換気口、`exit-sign.svg` は誘導標識です。

各SVGは400×500の基準座標で作成します。ゲーム内の大きさは `target.rect` で決まるため、元画像の縦横比と壁面の縦横比の違いは明示的な拡縮になります。画像は壁の面に貼られ、通路へ立体的には張り出しません。

再生成コマンドは次の通りです。

```sh
node tools/create-fixtures.mjs
```

この操作は同じ名前の設備SVGを再生成します。変更時は生成コードと生成物の両方をコミットします。壁面アトラスには触れません。

## 素材追加

1. 同一オリジンの `assets/` 以下へPNG・SVG・WebPを置きます。
2. 対象の `art.default` に通常の素材を指定します。
3. 状態別の素材を `art.on` などへ追加し、`appearance.set` で切り替えます。
4. 壁面の `rect` と、必要なら独立した `shape` を定義します。
5. バリデーターとブラウザーで遠近・左右・クリック範囲を確認します。

パスは英数字、アンダースコア、ハイフン、スラッシュで構成します。ネット上の画像URLを直接参照せず、プロジェクト内に素材を保持します。
