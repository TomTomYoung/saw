# 操作・モード仕様

## 探索

↑ / Wは一歩前進、↓ / Sは後退です。← / Aと→ / Dは90度旋回します。Shift＋左右キーまたはShift＋A・Dは向きを保った横移動です。Q・Eも左右の横移動です。画面の六つのボタンでも同じ操作を受け付けます。移動入力間隔は110ms以上に制限します。

マウスの移動で視点は回転しません。Pointer Lockも使用しません。四方向の視点を固定することで、詳細調査時に画面を狙えるようにします。

## 詳細調査

「詳細調べる」またはIで入ります。枠とモード表示が変わり、カーソルが照準になります。手の届く調査対象に重なるとポインターへ変化し、対象名と追従マーカーを表示します。

左ボタンの押下とクリック時の対象が一致したときだけ `click` を発火します。押してから別の対象へ移る、Canvas外へ出る、タッチがキャンセルされる、ウィンドウからフォーカスが外れる、といった場合は押下状態を破棄します。画面外で押してからCanvas上で離した操作も対象クリックになりません。

右クリックは `contextmenu` へ変換し、詳細調査中だけ標準コンテキストメニューを抑止します。右クリックを左クリックの調査として扱いません。右クリック対応イベントがない設備では何も実行しません。

対象のない場所では調べられるものがない旨をヒントに表示します。クリックで探索モードに戻したり、正面移動したりはしません。移動ボタンのクリックが調査対象のクリックへ流れることもありません。

Esc、I、画面内の「探索へ戻る」、操作パネルの「調査を終える」で終了します。終了時にホバー、押下対象、ヒントをクリアします。

## 文章表示

文章はCanvas内のダイアログに表示します。描画の背景は維持します。周囲の操作パネルとヘッダーをinertにし、フォーカスを進行ボタンへ移します。Tabも進行ボタン内に保持します。

Enter、Space、Esc、進行ボタンで一つずつ進みます。これらのキーのrepeatは無視します。文章を閉じるクリックはCanvasへ伝播しません。複数の文章の間にも移動を挟めません。最後の文章の後に残る状態変更命令を実行してから操作を戻します。

## タッチとキーボード

Pointer Eventsを共通窓口に使います。主ポインターだけを受け付け、Canvas内のタッチスクロールを止めます。タップも押下・解放・クリックとして同じ判定を通ります。

詳細調査時には「キーボードで調査箇所を選ぶ」を開けます。現在の向きから見え、手の届く対象をボタンで選択できます。この入口もクリックと同じイベント経路です。F2の開発情報には `pointerType: keyboard` と表示します。Ctrl / Alt / Metaを含むブラウザー操作は奪いません。

## パネルと補助操作

Hまたは映像右上のボタンで操作パネルと地図を隠せます。映像内の戻すボタンと詳細調査終了ボタンは残ります。モード自体は変わらないので、パネルを隠していてもI / Escで調査を切り替えられます。

F2は開発情報です。現在地、モード、busy、フラグ、イベント回数、直近のマウスイベントと座標、保存エラーを表示します。通常のプレイヤー画面には出しません。

「最初から探索」は画面内で確認してから実行します。確認前のクリックだけでは保存内容を消しません。
