# adv移植記録

## 出典

移植元は [TomTomYoung/adv](https://github.com/TomTomYoung/adv) です。取得時のmasterは `65a82368ecda0fa823b1833adec954ea9182a013`、コミット名は `feat: 生成UIを整理し味方・魔物設定を実試遊へ接続` です。今回の作業でadv側は変更していません。

このコードは同じ所有者のリポジトリ間で、依頼された転用として取り込んでいます。確認した移植元に独立したライセンスファイルはありませんでした。新しい公開ライセンスを独断で付与していません。

## 取り込んだもの

`adv/src/view/dungeon.js` を `src/view/adv/dungeon.js` へ取り込みました。一人称のレイキャスト描画、壁の遠近、床テクスチャ、距離による暗がりが基盤です。

`adv/src/view/dungeon-relief.js` と `adv/src/view/dungeon-art.js` を同じ場所へコピーしています。前者は将来の凹凸地形用、後者は正規化した素材矩形を画像の実ピクセルへ変換します。これら二つの内容は移植時点から変更していません。

`adv/src/core/engine.js` の `move` で用いられている四方向の旋回・前後移動・横移動計算を `src/core/geometry.js` の `moveLocation` へ抽出しました。RPG固有のコスト・遭遇・パーティー処理は付けず、saw側の床判定で通行を決めます。

## saw用の変更

レイキャスト関数を `src/view/adv/raycast.js` へ切り出し、当たった場所がセル境界かどうかを示す `boundary` メタデータを追加しました。レイの進行と角抜け防止は元の計算です。

天井テクスチャの描画を追加しました。壁面の設備画像をレイごとに貼り付ける処理と、描画世代の管理を追加しました。後者は画像ロードが遅れた際の旧視点による描き戻しを防ぎます。

adv向けのスナップショット形式に合わせる `src/view/projection.js` を新設しました。詳細調査のポインター判定・イベントランナー・UI・ビル定義・素材・保存形式はsaw用に新しく作っています。

## 取り込まないもの

advの既存背景やキャラクター素材、シナリオ、町、戦闘、依頼、成長、魔法、アイテム管理、ダンジョン生成UIは含みません。利用していない大規模なゲームエンジン一式を起動する必要はありません。

## 更新方法

advの更新を再び取り込むときは、上記コミットと対象ファイルを比較してください。レイキャスターの焦点距離・目の高さ・壁のu座標規約を変えた場合は、sawの `geometry.js` と `inspection.js` も合わせて確認します。ブラウザー試験でマウス判定と素材位置の一致を必ず確認します。
