# SAW 仕様書

仕様バージョン 0.1.0。2026-10-03時点の実装を記述します。現段階の成果物は脱出ゲームの探索・調査・イベント応答基盤です。

## 読む順序

1. [全体仕様](SPECIFICATION.md)：対象範囲、画面、ビル、状態、未実装項目。
2. [操作・モード仕様](INPUT.md)：移動、詳細調査、マウス、タッチ、キーボード、入力競合。
3. [マウスイベント仕様](EVENTS.md)：判定座標、データ、ハンドラー、命令、追加例。
4. [構成・保存仕様](ARCHITECTURE.md)：各モジュールの責務、描画経路、保存形式。
5. [素材仕様](ASSETS.md)：アトラス、設備、制作元、再生成、追加方法。
6. [adv移植記録](PORTING.md)：取り込んだファイル、元コミット、変更箇所。
7. [試験仕様](TESTING.md)：自動試験、手動確認、既知の制約。
8. [拡張方針](ROADMAP.md)：シナリオ・謎解きを入れる前の接続点。

実装の正本は `data/building.json` と `src/` です。仕様変更時は対応する文書と試験も更新します。HTMLビューアーはこのMarkdownを直接読みますので、文章の二重管理はありません。
