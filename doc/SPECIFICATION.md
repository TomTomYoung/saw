# 全体仕様

## 目的と範囲

advのグリッド式一人称探索を、現代の古いビルを舞台にした脱出ゲームへ転用します。プレイヤーが歩き、向きを変え、任意の箇所へカーソルを合わせて詳しく調べられる基盤を実装します。

この版には物語の進行、登場人物、謎解きの答え、鍵と錠の依存関係、アイテム、勝敗・脱出条件を含めません。設備の短い観察文と配電盤の切り替えは、描画とイベント機構の確認に用いる動作サンプルです。既存advの戦闘・町・クエストデータは読み込みません。

## 空間

13列×12行の単一フロアです。床を `.`、壁を `#` とする直交グリッドで表現します。座標は左上原点、xが東方向、yが南方向です。プレイヤーはセルの中心に立ち、北・東・南・西の四方向を向きます。

入口の現在地は `(6,9)`、北向きです。南側通路から中央廊下へ進み、管理室、西側・東側事務室、西側・東側倉庫を歩けます。壁の衝突と描画は同じマップを使います。小部屋の床も実際の空間です。

壁に固定した9箇所の調査対象があります。古い配電盤、入口の掲示板、インターホン、誘導標識、管理室の鉄扉、西側と東側の窓、倉庫の換気口、倉庫の掲示物です。鉄扉はこの版では壁面設備であり、その先へ開通する機能はありません。

## 画面

主画面には一人称映像、現在の区画、座標と方角、現在のモード、パネル表示切り替え、操作ヒントを表示します。右側に踏査地図、下側に移動・詳細調査ボタンと直近の観察記録を置きます。小さい画面では縦に積み、ページの横方向にはみ出さない配置にします。

Canvasの内部解像度は800×400です。表示も常に2:1を保ち、CSSの拡大縮小後の矩形からマウス座標を正規化します。画像の余白を含むobject-fit表示は使いません。

地図は現在地の周囲1セルを踏査済みにします。目的地マーカーや謎解きの正解は示しません。現在地の矢印は向きを表示します。探索記録は最大40件を保存し、画面には直近4件を表示します。

## 状態

通常は `explore`、詳細調査中は `inspect` です。文章表示や残りのイベント命令がある場合は `busy` が成立します。文章を閉じると元の調査を続けられます。調査終了は明示的なボタン・Esc・Iで行います。

`inspect` 中は前後移動・旋回・横移動をすべて拒否します。`busy` 中は移動、調査開始・終了、新規のマウスイベント、パネル切り替えを拒否します。次の文章への進行だけを受け付けます。長押しによる文章の連続スキップも行いません。

## 完成条件

1. ビル内を歩き、壁で停止し、部屋へ入れること。
2. 詳細調査でマウスを自由に動かし、見えている設備にだけ反応すること。
3. 対象別にマウスイベントを定義し、文章、状態変更、外観変更を実行できること。
4. 調査・文章表示中の移動と連打を隔離できること。
5. 画面の拡大縮小、タッチ、保存復元でも同じ対象と状態を扱えること。
6. 素材・仕様・テストをリポジトリに揃え、外部サービスなしで起動できること。
