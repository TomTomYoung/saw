# 試験仕様

## 自動試験

`npm run check` はマップ・イベント・素材参照・JavaScriptの相対importを検証し、Nodeの動作試験を実行します。テストは `tests/engine.test.mjs` にあります。

1. 全対象の到達可能性と正面からの選択。
2. 四方向の前後移動、旋回、横移動、壁の衝突。
3. 詳細調査中の移動禁止と、終了後の再開。
4. CSSサイズに依存しない座標正規化と不正座標の排除。
5. 可視性・射程・壁による遮蔽。
6. マウスイベントの情報、配電盤の状態と外観、文章中の再入禁止。
7. 押下と解放の不一致、キャンセル、右クリックの分離。
8. pointerleaveとモード終了時のホバー破棄。
9. once、複数文章、遅延した状態変更、対象無効化。
10. 表示条件と優先順位。
11. 保存復元と壊れたデータの拒否。
12. 不正なイベント命令とホバー副作用の拒否。
13. 矩形以外の形状と、レイの角抜け防止。

`npm run test:browser` はChromiumで実際にページを開き、描画、マウス移動、クリック、モーダルの入力隔離、キーボード、リロード復元、パネル切り替え、カニ歩き、タッチを確認します。1440px、900px、390pxの画面幅で横はみ出しと座標一致を確認します。スクリーンショットは `test-results/` に保存し、Git管理には含めません。

## 実行

```sh
npm run check
npm ci
npx playwright install chromium
npm run test:browser
```

実行環境によってNodeのテスト子プロセスが制限される場合は、内容を変えずに `node --test --test-isolation=none tests/*.test.mjs` で確認できます。

## 手動確認

入口から前へ一歩、右を向く、詳細調べる、配電盤へマウス移動、クリックの順に操作します。カーソルと対象名が変わり、表示灯と計器の針が切り替わります。文章表示中の矢印キー・連打は状態を変更しません。文章を閉じると同じ向きで詳細調査を継続します。

右クリックで配電盤の観察文を表示します。この操作では電源状態を変えません。調査を終了し、ページを再読み込みすると位置と配電盤の状態が残り、探索モードで再開します。

Hでパネルを隠しても画面内の復帰ボタンが残ることを確認します。画面幅を変更しても素材と判定位置が一致すること、スマートフォン相当の幅でボタンと文章が操作できることを確認します。

## 既知の制約

現版は平面一層・直交グリッド・四方向視点です。壁面設備の調査が対象で、床置きの立体物やドラッグ装置、拡大された専用調査画面は実装していません。壁面の素材を離れて見ても表示はされますが、調査にはreachの距離制限があります。

キーボード候補は壁面の複数点を投影して可視性を調べます。極端に細い形状や、ほんの一部だけ見える多角形では候補へ出ない場合があります。通常の矩形設備の操作はブラウザー試験で確認します。ピクセル単位の透明領域判定はありません。

画像読み込みに失敗したとき、adv由来の描画は単色へフォールバックします。配布前はファイル参照検証に加え、ブラウザー試験のHTTPエラー確認を通してください。
